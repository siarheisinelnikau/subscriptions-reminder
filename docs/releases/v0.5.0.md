Subscriptions Reminder has a compact desktop interface with a subscription table, smaller typography, and Light, Dark, and System themes.

### Redesigned

- Replace large subscription cards with rows showing name, notes, price, billing period, expiry, reminder lead time, status, and actions. Ten complete records fit at the default 1000 × 760 window size in Compact mode.
- Keep Renew and Edit directly accessible; move Pause/Resume and Delete into the row menu. Long names and notes remain available on hover and in the editor.
- Replace oversized summary cards with one compact summary bar. Retain search and attention/paused filters, and render only visible rows in large lists.
- Remove the sidebar and duplicate navigation. Add, Import, and Settings are available from the subscription header; secondary screens have a Back action. Google Drive is a Settings tab.
- Use Multi-Monitor Brightness's dark palette and Windows Segoe UI typography: 13 px body text and 12 px buttons. Load the installed Windows font locally without redistributing its font file.
- Organize Settings into General, AI provider, Notifications, Google Drive, and Storage & updates. Startup, reminders, cloud storage, and updates remain available.
- Make image review use the available width, collapse the source-image preview, and keep detected records compact. Google Drive details and optional help are collapsible.

### Added

- System, Dark, and Light appearance choices under Settings → General. Theme selection applies immediately and is saved separately from other unsaved settings. System follows Windows theme events without polling.
- Compact, Standard, and Large subscription sizes. Row height and spacing change immediately while the text size stays readable; the choice is saved on this computer. Compact is the default.
- Current documentation captures of the subscription table, Settings tabs, Drive, image review, and editor. Demo mode includes twelve sample subscriptions.

### Verification

All 37 unit tests pass, with formatting and Clippy checks. The packaged Windows executable passed three native desktop regressions covering hidden startup, retained font uploads, repeated tray callback restoration, duplicate launch, and hidden Quit. Actual frame captures were inspected in Light and Dark modes. Image-import layout was exercised with a local deterministic HTTP response, without an external AI request.

CPU/GDI rendering, event-driven redraws, unchanged-frame skipping, settings, and subscription storage are retained. The complete physical tray-menu and Google-account synchronization checklists remain separate from native callback and HTTP-fixture coverage.

### Download

**SubscriptionsReminder-v0.5.0.exe** is one portable executable for Windows 10/11 x64. Existing subscriptions and encrypted credentials are preserved. Settings without a theme choice default to System. **SHA256SUMS.txt** contains the checksum.

Google Drive retains the v0.4.2 Testing limitation: only registered Google test users can sign in, and Google may require reconnection after seven days. Real Google-account synchronization still requires account-owner verification.
