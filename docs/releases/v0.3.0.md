Subscriptions Reminder now connects to Google Drive directly with browser sign-in and automatic synchronization. Drive for desktop and a synced folder are no longer required.

### Added

- A Google Drive screen with Desktop OAuth configuration import, browser sign-in using PKCE, session refresh, manual sync, automatic sync, and local disconnect.
- A local offline copy with automatic upload after edits and remote checks every 60 seconds. Network failures preserve local changes and retry with backoff.
- Per-installation replication snapshots that merge independent edits and retain deletion history so stale snapshots do not restore removed subscriptions.
- Conflict review for concurrent edits to the same subscription, including edit-versus-delete. Choose a version or keep the subscription versions as separate records.
- Last-sync status and a sidebar indication for connection, offline state, and unresolved conflicts.

### Improved

- Local-storage settings now point to direct Google Drive connection instead of requiring a Drive desktop folder.
- Google OAuth credentials and refresh tokens stay local, protected with Windows DPAPI. AI/Telegram credentials, source images, and notification history are excluded from cloud snapshots.
- Current screenshots and a step-by-step Google Cloud setup guide are included in the README.

### Setup and verification

**A Google Cloud Desktop OAuth client is required. This release does not bundle a shared client.** Enable Drive API, configure app-data permission, download the Desktop client JSON, import it in the application, and complete sign-in in your browser. See the setup guide in the repository. External Google OAuth apps left in Testing may require reconnection after seven days.

All 35 automated tests pass locally. They cover PKCE, callback validation, Windows callback socket behavior, token refresh and rotation, restricted Drive requests, pagination, retries after unconfirmed uploads, offline edits and deletions, concurrent conflicts, and edits made during a download. Real Google-account sign-in and synchronization are **not yet verified**, because no OAuth project/client has been supplied. Existing reminder, storage, and AI-import tests also pass.

### Download

Download **SubscriptionsReminder-v0.3.0.exe** for Windows 10/11 x64. It remains one portable executable with a statically linked C runtime. `SHA256SUMS.txt` contains the checksum. Existing local data and settings are preserved. Cloud payloads use HTTPS and Google's storage protection; master-password encryption is not included in this release.
