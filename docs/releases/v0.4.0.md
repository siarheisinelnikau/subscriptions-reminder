Google Drive connection now uses the application's built-in Desktop OAuth client. Open Google Drive, click Connect Google Drive, and choose an account in the system browser. End users no longer need to create a Cloud project or import a JSON file.

### Improved

- Moved custom OAuth client import into a collapsed Advanced section, with an action to return to the built-in connection while disconnected.
- Kept existing sessions bound to their original OAuth client across updates, preserving their refresh-token audience and cloud replication identity.
- Kept OAuth configuration out of the source repository. Local builds use an ignored JSON file; release builds receive it from GitHub Actions Secrets and refuse to publish a build without the configured connection.
- Documented that Desktop client parameters remain extractable from the distributed EXE; account tokens stay local and are not bundled.

### Current Google availability

The bundled Google project is currently in Testing. Only registered test users can sign in, and Google may require reconnection after seven days. Unrestricted public sign-in still requires the maintainer to complete production configuration and any Google verification requirements.

### Validation and download

All 37 local automated tests pass, including bundled-client validation and preservation of an existing session's client. Real Google account sign-in and a cloud round-trip still require an account-owner check.

Download **SubscriptionsReminder-v0.4.0.exe** for Windows 10/11 x64. The application remains one portable executable; existing settings and subscriptions are preserved. **SHA256SUMS.txt** provides the executable checksum.
