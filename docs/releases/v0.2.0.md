Subscriptions Reminder can now fill in subscriptions from an image using your own AI connection.

### Added

- AI-Hub, OpenRouter, and custom OpenAI-compatible connection profiles, with separate URLs, model IDs, and Windows-encrypted API keys.
- Vision model selection through the service's models endpoint, plus manual model IDs for compatible servers.
- Screenshot and receipt import from PNG, JPEG, and WebP files, drag and drop, and the Windows clipboard.
- Automatic recognition after attaching or pasting, followed by an editable preview of detected subscriptions, dates, prices, currencies, billing periods, and notes.
- Batch saving with validation of every selected record and skipping of exact existing duplicates. Missing expiry dates are left for review instead of being guessed by the application.

### Improved

- The Save settings action stays visible at the top of Settings.
- Control outlines are clearer against the dark background.
- README screenshots now come directly from the running application's rendered frames, without cursor overlays.

### Verification

All 16 automated tests passed locally, including compatible HTTP requests, bearer authentication, redirect blocking, response parsing, and atomic batch import. A live AI-Hub Universal request correctly recognized three demonstration subscriptions with their expiry dates, prices, and currency. OpenRouter uses the same tested protocol; no paid OpenRouter request was made.

### Download

Download **SubscriptionsReminder-v0.2.0.exe** for Windows 10/11 x64. It is a single portable executable; no installer or Rust runtime is required. `SHA256SUMS.txt` contains the checksum. Existing local subscription data and settings are preserved.

AI import is optional and requires a configured vision-capable model. Selected images are sent to that provider; provider charges may apply. See the README for setup and the verification notes for remaining manual checks.
