Subscriptions Reminder v0.6.0 adds a six-language interface and a compact workspace with instant language and appearance choices. This release includes the changes since the preceding published v0.4.2 release; v0.5.0 was a local development milestone.

### Added

- Choose English, Russian, French, German, Spanish, or Italian in **Settings → General → Appearance → Language**. Native language names make the menu recognizable in every locale.
- Translate the subscription list, search and filters, editor and delete dialog, settings, AI image import, Google Drive connection and conflict review, update actions, tray menu, and reminder messages. Names, notes, prices, currency codes, paths, and model IDs retain their original content.
- Switch **System**, **Light**, and **Dark** appearance without restarting. Language, theme, and row size save immediately and locally. System mode follows native Windows theme events.
- Choose Compact, Standard, or Large rows while preserving readable text sizes.

### Improved

- Replace large subscription cards with a full-width table, compact summary, and aligned pricing, expiry, status, and actions. Search and attention/paused filters stay directly accessible, and large lists construct only visible rows.
- Keep Renew and Edit on each row, with Pause/Resume and Delete in its menu. Give translated action labels more horizontal room.
- Group General, AI provider, Notifications, Google Drive, and Storage & updates in one Settings surface. Image review uses the available width with a collapsible source image.
- Reuse the shared portable updater for release discovery, progress, checksum and executable validation, installation, rollback, and restart. Preserve the saved startup-check opt-out and existing data-directory restart arguments.
- Include native application and tray icon sizes for Windows scaling.

### Fixed

- Stop hidden or minimized background repaint wakeups before UI layout as well as rasterization and presentation. Restore and quit commands remain available.
- Preserve older settings without a language field, including their selected theme and update-check preference. Unknown language values fall back to English.
- Keep Google Drive status messages in a canonical form so switching the interface language can refresh an existing connection status immediately.

### Download and upgrade

**SubscriptionsReminder-v0.6.0.exe** is one portable Windows 10/11 x64 executable. **SHA256SUMS.txt** contains its checksum. Existing subscription data and encrypted credentials are preserved. The in-app updater supports both current single-architecture asset names and historical `-x64` names.

Google Drive retains the v0.4.2 Testing limitation: only registered Google test users can sign in, and Google may require reconnection after seven days. Real Google-account synchronization, Telegram delivery, physical tray interactions, and a full newer-release installation round-trip require separate account/device verification. Technical service and operating-system error details can remain in their original language.

### Verification

Focused catalog, placeholder, original-data preservation, and settings-migration regressions are included alongside the existing data, reminder, AI HTTP-fixture, synchronization, and updater tests. Current local validation is recorded in [verification notes](../verification.md).
