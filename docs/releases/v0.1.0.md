The first release of Subscriptions Reminder, a portable Rust desktop app for Windows 10/11 x64.

### Added

- Subscription tracking with expiry dates, configurable advance reminders, optional prices, and notes.
- Search, pause/resume, editing, deletion confirmation, and renewal for weekly, monthly, quarterly, and yearly subscriptions.
- Windows notification reminders with a persistent tray icon, background monitoring, and optional Windows startup.
- Optional Telegram bot delivery, with the bot token encrypted locally for the Windows account.
- Local JSON storage, previous-file backups, and support for a data folder managed by Google Drive for desktop.
- Nonblocking startup update checks, a persistent opt-out, manual checking, and user-initiated download and installation with SHA-256 verification.

### Download

Download **SubscriptionsReminder-v0.1.0.exe**. This is a single Windows x64 executable with a statically linked C runtime. No installer or Rust installation is needed. `SHA256SUMS.txt` contains its checksum.

### Notes

- Reminders require the app to be running on a powered-on computer while you are signed in. Closing the main window keeps it running in the tray; Quit stops it.
- Telegram is disabled until you configure your own bot and chat ID. Real Telegram delivery requires valid bot credentials.
- Google Drive support uses an existing synced desktop folder. There is no direct Google sign-in or simultaneous-edit merge.
- This initial portable executable is unsigned.
- Automated tests pass, and the dashboard and Settings were inspected in a running packaged build. Interactive tray-reopen, real notification delivery, Telegram delivery, and full updater installation still need manual confirmation; see the repository's verification notes.
