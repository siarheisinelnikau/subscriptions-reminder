Subscriptions Reminder now renders its interface on the CPU and displays it through Windows GDI. It also simplifies Google Drive connection to browser sign-in with the application's bundled Desktop client.

### Improved

- Replace the OpenGL renderer with CPU rasterization and GDI bitmap presentation. The Windows build creates no OpenGL or DirectX context.
- Wait for input, background results, or scheduled work while idle. Coalesce input-driven frames at up to 60 FPS, skip unchanged scenes, and reuse the bitmap for Windows expose events.
- Stop painting hidden and minimized windows while continuing to process restore and quit commands. Preserve pending font and image uploads until the next visible frame.
- Remove the unconditional 15-second redraw timer. Refresh date labels at local midnight and wake the interface when external data or background status changes.
- Connect Google Drive through the browser without requiring each user to create a Cloud project or import a JSON file. Custom Desktop clients remain available under Advanced.
- Preserve existing Google sessions' original client across updates. Keep OAuth configuration out of Git and inject it into trusted release builds from GitHub Actions Secrets.

### Verification and limitations

Formatting, Clippy, unit tests, and opt-in desktop regression results are recorded in [verification.md](https://github.com/siarheisinelnikau/subscriptions-reminder/blob/main/docs/verification.md). Desktop tests exercise actual window handles and tray callback dispatch.

All 37 unit tests and three desktop regressions passed. Short four-second visible-idle and hidden CPU samples measured 0.00% of one logical core on the test machine. In a mixed restore/pointer test, 172 of 242 visible UI passes skipped an unchanged scene. The user confirmed smooth cursor and desktop behavior with this build, including hiding and reopening the window. These results do not guarantee zero CPU use during interaction or identical behavior on every machine; the complete physical tray-menu checklist remains separate from callback regression coverage.

The bundled Google project remains in Testing. Only registered test users can sign in, and Google may require reconnection after seven days. Real browser sign-in and a cloud round-trip still require account-owner verification. Desktop client parameters are extractable from the EXE; personal account tokens remain encrypted locally.
